Modifications, 2026: converted to Geonkick MPC native full-instance .xpl files;
routing adapted to the MPC kit model and stereo output; embedded samples retained
up to the original 44.1kHz engine's four-second source-buffer limit. Original
complete envelope data is retained in the synthesis bank. Native envelope edits
use the MPC port's existing sixteen-knot editor. Humanizer is omitted as requested;
none of these factory files enables it. Kit choke groups/mute/solo and separate
outputs are not implemented; these differences are listed in the conversion report.
