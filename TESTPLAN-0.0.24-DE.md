# Geonkick MPC0.0.24 testen

- In SOUND Layer1/2/3 unterschiedliche Klänge einstellen, jeweilige Layer-Gains
  aktivieren. Die grüne Wellenform gehört jetzt zum jeweiligen Layer; ein stummer
  Layer zeigt eine flache Linie. Die orange Hüllkurve und Schnellregler folgen
  weiterhin dem zuletzt editierten Oszillator dieses Layers.
- Zwischen SOUND-Tabs wechseln: keine Neuberechnung/Knackser. MASTER/MIX und
  ENVELOPE behalten die fertige Gesamtwellenform inklusive Master-Effekte.
- MASTER/SAMPLES: Ordner öffnen, SET DEFAULT drücken. In anderen Ordner wechseln,
  OPEN DEFAULT drücken: der gemerkte Ordner wird geöffnet. Nach neuem Laden des
  Plugins/Neustart ebenfalls testen. Keine Änderung an globalen MPC-Einstellungen.
- WAV laden, spielen, Projekt speichern und neu laden. Der Startordner ist eine
  lokale Plugin-Einstellung; WAV-Audio bleibt im Projekt enthalten.

Roadmap: Originalpresets/Soundbanken über native MPC-Presets und Sounds-Browser;
kleines KIT-Lerntutorial vor Release. Kein Store-Benchmark vor finalem Release.
